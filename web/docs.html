Basis Lab API

A zero-auth, read-only API for normalized venue candles and cross-market basis candles. Times are Unix milliseconds. Responses are JSON.

The public chart uses the live Rust service at basis-lab-sg.onrender.com. The OpenAPI link below is a static copy of the same contract.

OpenAPI 3.1 specification

GET/api/v1/venues

Venue identifiers, market types, and supported intervals.

GET/api/v1/markets

venue, query?, limit? · venue-native symbols with normalized BASE/QUOTE identities

curl '/api/v1/markets?venue=bybit_perp&query=WLFI%2FUSDT'
GET/api/v1/tickers

venue?, query?, limit? · cached normalized cross-venue ticker search

curl '/api/v1/tickers?query=WLFI%2FUSDT&limit=100'
GET/api/v1/tickers/suggest

source_venue, source_symbol, target_venue, limit? · ranked equivalent native symbols, including Hyperliquid HIP-3 and aliases such as US500 → SP500

curl '/api/v1/tickers/suggest?source_venue=ondo_perp&source_symbol=US500-USD.P&target_venue=hyperliquid_perp'
GET/api/v1/candles

venue, market, interval, from, to, limit?


  
GET/api/v1/compare
left_venue, left_market, right_venue, right_market, interval, from, to, limit?, scale?

  
Comparison semantics

  
The default scale=10000 returns basis points: (left / right - 1) × 10000. Markets must resolve to the same canonical base asset; use ticker suggestions to find the venue-native equivalent. Candle open and close use matching source fields. The high is left.high / right.low; low is left.low / right.high. These are conservative bounds because venue OHLC extremes may occur at different moments inside the bar. Each venue's base-asset volume is returned separately when available and drawn in independently scaled A and B chart panes. When an upstream venue limits its history window, Basis Lab returns the newest supported subset rather than failing the entire comparison.

  
Live follow

  
The browser's Follow live control connects directly to both venues' public WebSocket feeds after loading the historical comparison. It normalizes updates to the selected UTC interval and paints a comparison candle only after both venues report the same opening timestamp. Connections automatically retry and resubscribe. Ondo's public feed supplies mark-price ticks, so its live side is labeled mark-derived and has no synthetic volume. Binance perpetual also uses a visibly labeled BBO-midpoint fallback whenever its kline stream is silent.

  
Operational limits

  
Maximum 1,500 returned candles, 366-day range, 20,000 source intervals, bounded 15-second candle cache, five-minute ticker catalogs, 12 MiB upstream response cap, and a two-second concurrency queue. Upstream exchange limits can be lower.
