Basis Lab API

A zero-auth, read-only API for normalized venue candles and cross-market basis candles. Times are Unix milliseconds. Responses are JSON.

OpenAPI 3.1 specification

GET/api/v1/venues

Venue identifiers, market types, and supported intervals.

GET/api/v1/markets

venue, query?, limit?

curl '/api/v1/markets?venue=bybit_perp&query=WLFI'
GET/api/v1/candles

venue, market, interval, from, to, limit?


  
GET/api/v1/compare
left_venue, left_market, right_venue, right_market, interval, from, to, limit?, scale?

  
Comparison semantics

  
The default scale=10000 returns basis points: (left / right - 1) × 10000. Candle open and close use matching source fields. The high is left.high / right.low; low is left.low / right.high. These are conservative bounds because venue OHLC extremes may occur at different moments inside the bar.

  
Operational limits

  
Maximum 1,500 returned candles, 366-day range, 20,000 source intervals, bounded 15-second cache, 12 MiB upstream response cap, and a two-second concurrency queue. Upstream exchange limits can be lower.
